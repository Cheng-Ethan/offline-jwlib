# 常见问题 / FAQ

[English](../en/user/FAQ.md) · [使用指南](USAGE.md) · [移动端说明](MOBILE.md)

## 应用会联网吗？

不会发起业务请求。没有账号、遥测或外部脚本；远程图片和样式会在阅读时剥离，外部链接点击会被拦截并提示。所有依赖都打包在同一个 HTML 里，正常运行不需要网络。

## 我的书和笔记保存在哪里？

全部保存在你当前浏览器或 App 的本地数据中：

- 出版物、图片、笔记、书签、高亮、标签、历史和分类；
- 界面语言、注音开关、语言包等偏好设置。

没有服务器，也没有账号。清除浏览器/App 数据会丢失这些内容，请定期导出备份。

## 为什么升级后书不见了？

不同 HTML 项目可能使用相互隔离的本地数据空间。新 HTML 不会自动继承旧项目里的书。正确做法是：在旧项目导出完整备份 → 在新项目打开新 HTML → 恢复备份 → 验证正常后再删除旧项目。

## 支持多大的 JWPUB？

建议单文件不超过 380 MB，内部文件不超过 8000 个，单篇文档不超过 48 MB。低端手机即使低于这些值也可能因内存不足失败。大文件建议先在桌面 Chrome 导入，再通过备份迁移到手机。

## 视频和音频呢？

不保存音视频，正文中会显示离线提示。这是为了保持单文件体积和离线可用性。

## `jwpub://c/` 注释链接一定能用吗？

应用会尝试在本地匹配注释数据，但现有样本缺少包含这类链接的出版物，因此实际地址格式仍需样本验证。匹配不到时会显示原因，**不会联网**。

## 怎么切换界面语言？

右上角语言按钮可以切换内置语言。你也可以导入自己的语言 JSON 文件，详见 [使用指南](USAGE.md#6-语言与分类)。这叫做**用户语言包（插件 v0）**：只能替换界面文字，不能运行代码或读取你的书。

## 可以自己改分类吗？

可以。在「出版物」卡片菜单（⋯）里能新建分类或把书移动到其他分类。自定义分类只保存在你的设备上，不会影响内置分类规则。

## 备份安全吗？

备份文件是 JSON，**没有加密**，里面包含书名和你的笔记。请不要在共享电脑上随意导出或存放备份；升级、换设备前务必备份。
