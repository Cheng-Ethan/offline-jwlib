# 使用指南 / Usage

[English](../en/user/USAGE.md) · [安装与构建](INSTALL.md)

## 1. 第一次使用

1. 打开 `offline_library.html`。
2. 进入「更多 → 导入 PUB」（或主界面的导入按钮）。
3. 选择一个或多个 `.jwpub` / `.pub` 文件，可批量导入。
4. 导入完成后，从「圣经 / 出版物 / 每日经文 / 聚会」栏目打开资料。

导入时应用会在本地完成：ZIP 读取（必要时修复缺失 central directory）→ manifest 解析 → SQLite 读取 → 解密 → 文档/资源提取 → 保存到本机。大文件会显示逐本进度；单份文档失败会隔离，整体失败率超过阈值才终止。

## 2. 五个栏目

| 栏目 | 内容 |
|---|---|
| 圣经 | 检测到 Bible 数据的 JWPUB，可进入卷/章目录 |
| 出版物 | 按分类浏览、搜索、收藏、调整分类、删除 |
| 每日经文 | `DatedText` 生成的按日期文档，内容以出版物自身为准 |
| 聚会 | 聚会工作手册、节目、大会资料 |
| 更多 | 导入 PUB、备份与恢复、使用说明、设置与诊断 |

分类由 `src/categories.json` 的规则匹配出版物符号、类型、标题等字段得到；规则未命中时由源码兜底。用户也可以在卡片菜单里自定义分类。

每日经文阅读页保持简洁：不显示底部操作栏，分页使用「前一日 / 后一日」；阅读设置在右上角三个点菜单中。需要记笔记时，点按段落或经文即可在工具栏添加。

## 3. 阅读器

- 题头：返回、两行标题（出版物名称 + 当前章节/文章）和右上角三个点。
- 三个点菜单：目录、搜索、上一章/下一章（每日经文为前一日/后一日）、书签、笔记、语言版本、拼音、放大/缩小字号。
- 目录：手机为抽屉，桌面宽屏（≥1100px）为三栏，中间是目录，右侧是正文。
- 点按经文或段落：选中的那一节或那一段会以明显的蓝色整块高亮；再点同一处或点旁边会取消选中。点按页边、段间空隙不会选中内容。
- 回答框：出版物里的「你会怎么回答？」等输入框默认只占一行高度，输入内容变多时才自动向下长高。
- 工具栏里的“信息”按钮：显示当前这一节/段的脚注、串珠（相关经文）和引用文章；经文会显示章节名和正文，外部链接会说明离线不可用。
- 相关链接浮窗：题头就是链接名称，点击题头会打开目标文章并定位到对应段落，这次跳转计入当前栏目的返回历史，点返回回到原出版物。
- 浮窗内点击需要联网的链接会弹出离线警告；警告显示在所有面板最上层，点右上角 X 只关闭警告，不关闭主浮窗。
- 搜索：可选择搜索范围（当前出版物、当前分类、所选出版物、全部出版物），结果按出版物分组，每组默认显示 5 条，可展开其余；支持最近搜索和“返回结果”。
- 内部链接：`jwpub://p/`（出版物）、`jwpub://b/`（圣经）、`jwpub://c/`（注释）会在本地匹配；匹配不到会显示原因，**不会联网**。
- 外链：会提示“不会尝试联网打开”。
- 远程图片/CSS：导入正文时会被剥离，避免离线文件偷偷联网。
- 栏目独立：每个底部栏目分别保存当前文章、返回历史和精确到段落的阅读位置；重新打开 HTML 或导入出版物后，各栏目仍从原位置继续。

## 4. 笔记、高亮与书签

- 高亮：在正文选中文本，出现标注工具栏后点四色圆片图标，展开黄、绿、蓝、红四个大圆点选择；保存为块索引 + 偏移，配合稳定 ID 跨语言/年份保留。
- 笔记：可折叠编辑器，支持撤销/重做；经文笔记可按节保存。有笔记的段落左侧显示铅笔标记。
- 选中已上色的文字时，整行合并为一个圆角边框，不会给每个字单独加框。
- 标签：给笔记/高亮打标签，便于在「更多」中集中管理。
- 书签：记录阅读位置。
- 历史：保留最近阅读与滚动位置。

> 这些数据默认以明文保存在本机，导出的备份也未加密。启用「应用锁」后，笔记、标签、划线、书签、历史、分类、原始文件名、原始包和备份都会加密；书名、目录、标注位置等元数据仍是明文。详见第 5 节。

## 5. 应用锁与恢复码

在「更多 → 设置与诊断 → 应用锁」中启用：

- 设置至少 6 位密码；首次设置会显示一次性**恢复码**，请离线保存。
- 之后启动/刷新需要密码；切到后台超过设定时间（5/15/30/60 分钟）会自动锁定。
- 忘记密码时用恢复码解锁，再在设置中更改密码。
- 恢复码也丢失时，只能「清空全部数据」重新开始；没有远程管理员后门。
- 启用应用锁要求所有出版物都有原始包并已切换为 source-first；没有原始包的旧书需要重新导入。
- 启用后原始包、笔记/标签/高亮/书签/历史/分类、原始文件名和备份都会加密；书名、目录、标注位置等元数据仍是明文。
- 启用期间会强制保持「保留原始包以便分享」和「以原始包为主」，避免新导入的书把正文写回明文；缺少原始包或原始包保存失败时，导入会被取消。最近搜索词只留在内存，不再写入本地存储。
- 应用锁不提供关闭开关，只能更改密码或重新生成恢复码。

## 6. 备份与恢复

### 导出

在「更多 → 备份与恢复」中：

- **备份整个图书馆**：导出 `offline-library-library-v2.json`，包含全部出版物、图片资源、笔记、标签、高亮、书签、历史、分类、界面设置、语言包和阅读位置；有原始包的书会一并包含原始 JWPUB，备份体积可能接近图书馆的两倍。
- **备份笔记**：导出 `offline-library-notes-v1.json`，仅含笔记、标签、高亮。

超过约 150 MB 时会先确认。实际文件因 Base64 编码会比估算更大。

### 重新导入出版物

在出版物卡片右上角「更多」或阅读器右上角菜单中选择「重新导入」，再选择同一出版物的新 JWPUB。应用会先读取新文件的出版物名称和 ID：

- 不是同一出版物时会拒绝，避免导错；
- 名称不同但出版物 ID 一致时，会提示并让你确认；
- 重新导入后笔记、标签、划线、书签和阅读历史保留。

### 分享原始 JWPUB

1. 「更多 → 设置与诊断 → 保留原始包以便分享」默认开启，可手动关闭；应用锁启用期间保持开启且不能关闭。
2. 之后导入的 PUB 会在应用内保留一份完整原始文件；导入完成后外部 `.jwpub` 文件可以删除。
3. 在出版物卡片或阅读器右上角菜单中选择「分享 → 导出 / 分享原始 JWPUB…」，可选择「原文件名」或「易读名称」。导出文件与导入时的 JWPUB 逐字节一致。

手机上会先打开系统分享面板。如果列表里没有 JW Library，选择「存储到文件」，再从「文件」App 里分享/打开给 JW Library；桌面浏览器则直接保存到下载目录。

如果这本书是在这个功能之前导入的，它会缺少原始包，分享菜单会提示重新导入一次；重新导入后原文件仍可删除。原始包会额外占用空间，完整备份会一并包含它，因此备份文件可能接近图书馆体积的两倍。

### 恢复

选择对应备份类型：

- 恢复整个图书馆：兼容 `offline-library-backup-v1/v2/v3` 与 `offline-library-library-v1/v2`；会按出版物 ID 覆盖/合并，并重映射旧 ID 以保持笔记对齐；v2 备份里的原始包会一起恢复。
- 恢复笔记：只接受 `offline-library-notes-v1`。

恢复整个图书馆使用 `file.stream()` 流式解析；浏览器不支持时会报错，请改用桌面 Chrome。恢复不是原子事务，失败可能留下部分数据，建议先备份当前数据。

格式细节见 [../dev/BACKUP_FORMAT.md](../dev/BACKUP_FORMAT.md)。

## 6. 语言与分类

### 界面语言

右上角语言按钮可切换内置界面语言（中/英/日/韩等）。界面语言与内容语言分离，切换界面不会改变正在阅读的出版物语言。

### 导入语言包

在右上角语言按钮的菜单中点击「＋」导入本地 JSON：

```json
{
  "code": "fr",
  "name": "Français",
  "locale": "fr-FR",
  "button": "FR",
  "messages": {
    "导入 PUB": "Importer PUB",
    "备份图书馆": "Sauvegarder la bibliothèque"
  }
}
```

字段说明：

- `code` 或 `lang`：2–8 位小写语言代码，必需；
- `messages` 或 `strings`：翻译字典，键是应用内原文，必需；
- `name` / `locale` / `button`：可选显示信息。

导入后会写入 localStorage，刷新后仍有效。也可控制台调用 `window.__offlineLibrary.registerLanguagePack(code, meta, messages)`。

### 自定义分类

在「出版物」卡片菜单（⋯）中可移动分类或新建分类。自定义分类只保存在你的设备上，不影响内置分类规则。

规则文件格式见 [../dev/PLUGINS.md](../dev/PLUGINS.md)。

## 7. 常见操作问题

| 问题 | 处理 |
|---|---|
| 提示“本地存储不可用” | 换用支持本地存储的现代浏览器；Sitecase 需确认容器权限 |
| 导入卡住或失败 | 查看导入报告；单份文件损坏可跳过；尝试桌面浏览器 |
| 图片不显示 | 确认原始 JWPUB 含资源；复杂字体/版式需真机验证 |
| 升级后书不见了 | 从旧项目导出备份，在新项目中恢复 |
| 外链打不开 | 设计如此：离线应用不会联网 |
| 恢复大备份失败 | 使用支持 `file.stream()` 的桌面浏览器，或分批备份 |

更多边界说明见 [FAQ.md](FAQ.md) 与 [../dev/TESTING.md](../dev/TESTING.md)。
